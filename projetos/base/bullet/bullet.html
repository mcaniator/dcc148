Bullet Hell

Crie um novo projeto e crie duas cenas: uma para representar a nave do jogador e outra para representar os projéteis. Ambas as cenas devem ter um nó raiz do tipo Area2D e filhos dos tipos Sprite2D e CollisionShape2D. Escolha alguns assets para representar tanto a nave quanto o projétil. Adicione um script ao nó raiz da cena do projétil e defina um sinal para saber se o projétil atingiu algo ou se saiu de cena, além de uma variável para defiir a sua velocidade. signal hit_or_lost @export var speed: float Conecte o sinal area_entered do nó raiz e emita o sinal hit_or_lost no corpo da função conectada. Para que o projétil afete somente os inimigos, e não o jogador, mude os layers de colisão do projétil da forma mostrada na figura abaixo. Opcionalmente, você pode renomear os layers clicando nos três pontos ao lado das camadas. Na função _physics_process, mova o projétil para a direita utilizando o seu sistema de coordenadas local. Caso o projétil tenha saído dos limites da tela, emita o sinal hit_or_lost. func _physics_process(delta: float) -> void: translate(transform.x * speed * delta) if not get_viewport_rect().has_point(position): hit_or_lost.emit()

Exercícios

  1. Adicione um script ao jogador e implemente o seu movimento. A nave deve poder se mover nas 4 direções. Utilize a função translate e atente-se para que não ocorra variação de velocidade ao se mover na diagonal.
  2. Adicione uma opção para o jogador atirar usando, por exemplo, a tecla Espaço. Ao fazê-lo, deve ser instanciado um projétil na posição corrente do jogador. Use a função Input.is_action_just_pressed para que o jogador precise pressionar repetidas vezes a tecla para disparar vários tiros.

Object Pool

Crie um novo script, desvinculado de qualquer nó. Para isso, na tela dos Scripts, selecione "Arquivo/Novo Script". Criaremos uma classe chamada ObjectPool. O cabeçalho do arquivo deve estar como no trecho de código seguir: class_name ObjectPool extends Node Crie duas variáveis do tipo @export para armazenar o tamanho da pool e a cena a ser usada para instanciar os objetos. Crie também um array de objetos do tipo Node2D e um inteiro para armazenar quantos objetos estão disponíveis. @export var object_scene: PackedScene @export var pool_size: int var objects: Array[Node2D] var available: int Na função _ready, pré-aloque o vetor e instancie todas as cópias da cena solicitadas. Cada instância deve ser instanciada com as funções de atualização do nó desabilitadas e marcadas como invisíveis. Apesar disso, toda instância deve ser adicionada à cena. O número de objetos disponíveis na pool, inicialmente, é o tamanho da pool. func _ready() -> void: objects.resize(pool_size) for i in range(pool_size): objects[i] = object_scene.instantiate() objects[i].process_mode = Node.PROCESS_MODE_DISABLED objects[i].hide() add_child(objects[i]) available = pool_size Crie uma função get_from_pool para retornar um objeto disponível, caso exista. Para evitar realocação do array, os objetos são apenas reposicionados no array, trocando o primeiro elemento com o último disponível e marcando a última posição como nula. Assim, funções como pop_at, append e outras similares não foram usadas aqui. func get_from_pool() -> Node2D: var obj = objects[0] available -= 1 objects[0] = objects[available] objects[available] = null if obj: obj.show() obj.process_mode = Node.PROCESS_MODE_ALWAYS return obj Crie uma função para devolver o objeto à pool. Esta função deve desabilitar o objeto novamente, reintroduzi-lo no array e incrementar a quantidade de disponíveis. func return_to_pool(obj: Node2D) -> void: obj.process_mode = Node.PROCESS_MODE_DISABLED obj.hide() objects[available] = obj available += 1 Agora que criamos esta classe derivada de Node, ela aparece como um nó customizado na lista de nós para incluirmos na cena. Assim, na cena do jogador, adicione um nó filho do tipo ObjectPool. Renomeie-o para "BulletPool" e configure os parâmetros no Inspetor. Crie uma cena principal e adicione instancie o jogador como uma cena filha. Execute o projeto para verificar se o jogador consegue movimentar a nave e disparar os tiros continuamente.

Exercícios

  1. Modifique o código do Exercício 2 para, ao invés de instanciar um objeto ao atirar, obter um novo projétil da pool e posicioná-lo no local onde o jogador se encontra.
  2. Crie uma cena para representar um inimigo. Este inimigo deve surgir à direita da tela e se movimentar continuamente para a esquerda. Ao colidir com um projétil ou com o jogador, o inimigo deve ser destruído. No caso de colisão com o jogador, o jogador também deve ser destruído.
  3. Altere a cena principal para incluir uma pool de inimigos. Os inimigos devem surgir continuamente à direita da tela a cada 1 segundo, em posições aleatórias no eixo y.
  4. Modifique o código de atirar do jogador para que seja possível apenas segurar a tecla Espaço para disparar vários tiros. Será necessário implementar um cooldown para que os tiros não sejam disparados todos em uma rajada única.
  5. Inclua um novo tipo de inimigo que também atira contra o jogador.
