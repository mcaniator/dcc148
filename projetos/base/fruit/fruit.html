Fruit Ninja

Neste exemplo, iremos organizar um pouco melhor os arquivos do projeto. Crie um novo projeto e, dentro da pasta gerada pela Godot, crie outras 3 pastas: cenas, sprites e scripts. Encontre imagens de frutas e bombas para usá-las como assets no jogo. Sugestões:
  • https://opengameart.org/content/pixel-fruit-pack
  • https://opengameart.org/content/bomb-sprite-vector-image
 Crie uma cena com um nó raiz do tipo Sprite2D (clicando na opção "Outro Nó") e nomeie-o como "Fruit". Crie uma segunda cena com um nó raiz do tipo Node e dê ao nó o nome de "MainGame". Adicione um script ao nó raiz da cena principal (selecione a pasta "scripts" na hora de criar o arquivo) e crie variáveis do tipo @export para armazenar a cena da fruta e as imagens. @export var fruit_scene: PackedScene @export var fruit_list: Array[Texture2D] @export var bomb: Texture2D Associe a cena da fruta e as imagens da pasta de sprites às respectivas propriedades geradas no Inspetor da cena principal após a criação das variáveis no passo anterior. Crie outras 3 variáveis auxiliares para indicar o objeto ativo no momento, a pontuação do jogador e uma flag para identificar se a fruta é ou não é uma bomba. var active_object: Node2D var score: int var is_bomb: bool Crie uma função new_fruit para instanciar uma nova fruta (ou bomba) em uma posição aleatória. func new_fruit() -> void: if active_object: active_object.queue_free() active_object = fruit_scene.instantiate() var rand_val = randf_range(0.0, 1.0) if rand_val > 0.8: active_object.texture = bomb is_bomb = true else: active_object.texture = fruit_list.pick_random() is_bomb = false active_object.position.x = randf_range(0, 1000) active_object.position.y = randf_range(0, 600) add_child(active_object) Crie uma outra função, chamada cut_fruit para verificar se a fruta é ou não uma bomba. Se for fruta, a função incrementa a pontuação; caso contrário, a pontuação é impressa e zerada. Ao final, uma nova fruta é criada. func cut_fruit() -> void: if is_bomb: print("Pontuação: " + str(score)) score = 0 else: score += 1 new_fruit() Na função _ready, inicialize a pontuação com 0 e chame a função new_fruit. Na função _process, inclua um código para verificar se o jogador pressionou a tecla Espaço e, em caso positivo, chamar a função cut_fruit. func _process(delta: float) -> void: if Input.is_action_just_pressed("ui_accept"): cut_fruit()

Exercícios

  1. Modifique o código para que não seja necessário destruir e instanciar o objeto repetidas vezes. O jogo deve instanciar uma única cópia da cena da fruta na função _ready, armazenar esta cópia em uma variável e apenas alterar a sua textura e sua posição toda vez que uma nova fruta for selecionada.
  2. Adicione um novo script ao nó raiz da cena da fruta e, na função _process, implemente uma lógica para mover a fruta em um movimento de ascensão e queda. A lógica é muito similar à implementada para o exemplo da bola quicando no projeto da aula anterior.

Detectando o mouse

Na cena da fruta, altere o tipo do nó raiz para Area2D (clique com o botão direito sobre o nó e selecionar "Alterar Tipo...". Adicione como filhos do nó raiz um Sprite2D e um CollisionShape2D. No nó CollisionShape2D, crie uma geometria do tipo "CircleShape2D" no campo Shape. Após a criação da geometria, clique sobre a propriedade para expandir as opções e modifique o raio do círculo para 250 (o tamanho ideal pode variar em função dos assets utilizados). No script da fruta, defina um novo sinal chamado "hit". signal hit No Mapa de Entrada das configurações do projeto, inclua uma nova ação associada ao botão esquerdo do mouse. Selecione o nó raiz (que agora é do tipo Area2D) e, na aba de Sinais, conecte o sinal mouse_entered. Na função que foi criada no script, adicione um código para emitir o sinal "hit" sempre que o botão esquerdo do mouse for pressionado. func _on_mouse_entered() -> void: if Input.is_action_pressed("mouse_left"): hit.emit() No script da cena principal, conecte o sinal "hit" emitido pela fruta à função cut_fruit. Para isso, inclua a linha de código abaixo no script. O local de inclusão da linha abaixo irá variar em função de você ter ou não feito o Exercício 1. active_object.connect("hit", cut_fruit)

Exercícios

  1. Modifique o jogo para que mais de uma fruta possa ser criada ao mesmo tempo. Faça com que uma nova fruta seja gerada a cada X segundos. Você pode usar um acumulador para somar a variável delta a cada frame, ou você pode utilizar o nó Timer.
  2. Inclua um nó do tipo Label na cena principal para exibir a pontuação do jogador.
  3. Crie uma tela de game over que permita ao jogador reiniciar o jogo.
