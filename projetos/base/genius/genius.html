Clique sobre a propriedade Gradient para expandir as opções e inverta a ordem do branco e do preto, de modo a tornar o gradiente como na figura abaixo. Ajuste também o tamanho da textura (no editor 2D ou via propriedades) para envolver completamente o retângulo colorido. Desabilite a luz desmarcando a propriedade Light2D/Enabled. Selecione o nó raiz e nas opções de dimensionamento do nó para containers (barra superior, ao lado da âncora), marque para Preencher e Expandir, tanto no alinhamento horizontal quanto no vertical. Adicione um script ao nó raiz e defina uma variável do tipo AudioStream marcada como @export. Cena principal

Crie uma nova cena e escolha como nó raiz um GridContainer. Nomeie o nó como "MainGame" e salve a cena. Instancie 4 filhas da cena do botão. Selecione o nó raiz e mude a propriedade Columns para 2. Mude a predefinição de âncora do nó raiz para "Centro" e defina um tamanho para o container na propriedade Size (no exemplo deste passo-a-passo, foi usado o valor 400 para x e y). Para cada instância, via Inspetor, atribua um dos áudios da pasta de assets à variável exportada anteriormente e atribua uma cor na propriedade Color. O resultado da cena deve ser similar ao da figura abaixo. Adicione um script ao nó raiz e crie as seguintes variáveis: var buttons: Array # referências aos botões da cena var sequence: Array[int] # sequúncia de inteiros que representam os índices dos botões a serem tocados var sequence_size: int # número de notas a serem tocadas

Exercícios

  1. Crie um método new_game no script principal conforme descrito abaixo: func new_game(): # limpa a sequência # gera uma nova sequência aleatória de botões # toca os botões na sequência, com intervalo de 1s
  2. Inclua na cena principal uma música de fundo e um botão de início. Ao clicar no botão, a música deve parar, o botão ficar invisível e o jogo deve ser iniciado.
  3. Faça uma função para verificar se a sequência fornecida pelo jogador bate com a sequência gerada pelo jogo. Para detectar quais botões foram pressionados pelo jogador, crie um sinal no script do botão e emita-o sempre que o jogador pressionar o botão. Passe uma referência ao próprio botão como parâmetro do sinal no momento da sua emissão. Em seguida, no script da cena principal, conecte os 4 botões a uma mesma função que recebe um objeto do tipo Control como parâmetro e compare esse objeto com as referências armazenadas no array de botões.
  4. Faça com que o tamanho da sequência aumente a cada vez que o jogador acertar a sequência. Ao errar, o tamanho da sequência deve ser restaurado para o valor default.
  5. Implemente uma animação para a tela de início (antes do jogador pressionar o botão de início), em que os botões acendem aleatoriamente junto com a música.
  6. Extra: troque o ColorRect da cena do botão por um nó do tipo Button e adicione uma nova style box ao botão. Dê a cada botão o estilo que desejar.
