Colossal Cave Adventure

Crie um novo projeto e copie o conteúdo da pasta de assets deste passo-a-passo para a pasta do projeto criada pela Godot. Vá em Projeto/Configurações do Projeto, na seção Renderização/Ambiente, e mude a Cor de Fundo Padrão para preto.

Tela de título

Crie uma cena com um nó raiz do tipo Interface de Usuário (Control), e dê a ela o nome TitleScreen. Lembre-se de salvar a cena (Ctrl+S). Selecione o nó TitleScreen e adicione um novo tema na propriedade Theme. Clique sobre o tema criado para expandir as propriedades e, no campo Default Font, associe o arquivo de fonte presente na pasta do projeto (ou outro de sua escolha). Na aba do tema que se abriu na parte inferior da tela, clique no botão Gerenciar Itens. Na tela que se abriu, selecione a aba Importar Itens, escolha o Button, marque a caixa de seleção de Importar e clique no botão Importar Seleção para importar todas as propriedades do botão. Feche a janela de importação e você verá à direita as propriedades importadas. Modifique, de preto para amarelo, as cores das propriedades font_color, font_focus_color e font_hover_color. Clique na seta para a direita para mover a lista de categorias de propriedades e selecionar a seção de "Caixas de Estilo" (Style Boxes). Nas propriedades focus, hover, normal e pressed, para cada uma delas, adicione uma style box e clique sobre a style box adicionada para abrir as propriedades no Inspetor à direita. Configure cada Style Box como a seguir: focus
  • Border Width: 2 (todas as bordas)
  • Border Color: amarelo
  • Expand Margins: left = 10, top = 5, right = 10, bottom = 5
 hover
  • BG Color: preto
  • Border Width: 2 (todas as bordas)
  • Border Color: amarelo
  • Expand Margins: left = 10, top = 5, right = 10, bottom = 5
  • Content Margins: left = 0, right = 0
 normal
  • BG Color: preto
 pressed
  • BG Color: amarelo
  • Expand Margins: left = 10, top = 5, right = 10, bottom = 5
 Salve o tema construído clicando na seta ao lado da propriedade Theme da Title Screen e escolhendo a opção "Salvar como". Um arquivo do tipo .tres será salvo na pasta do projeto. Adicione como nós filhos à cena (Ctrl+A) um Label e um Button. Selecione o Label, mude a propriedade Text para "Colossal Cave Adventure" e coloque uma quebra de linha antes da palavra Adventure. Mude também a propriedade Horizontal Alignment para "Center". Na propriedade LabelSettings, crie um novo recurso, clique sobre ele após a criação para expandir as propriedades, e mude o tamanho da fonte para 100. Selecione o botão e mude a propriedade Text para "INICIAR". Na propriedade Theme Overrides da seção Control do botão, mude o Font Size para 32. Para posicionar o label no centro da tela, selecione-o e use a Predefinição de Âncora "Centro". Para posicionar o botão na tela, selecione-o e aperte a tecla W (alternativamente, clique no ícone do Modo de Movimentação na barra de ferramentas da Cena 2D). Isto ativará os eixos de movimentação sobre o elemento, permitindo movê-lo na tela. Check: ao final do processo, a tela inicial deve estar como na imagem abaixo. Agora selecione o nó TitleScreen e adicione um script a ele (clicando com o botão direito sobre o nó, ou clicando sobre o ícone do script ao lado da caixa de filtros). Apague qualquer código que for gerado automaticamente, mantendo apenas a linha extends Control. Selecione novamente o botão, vá na aba de Sinais (à direita do Inspetor) e associe ao botão o sinal pressed. Na janela que se abrirá, clique no botão "Conectar" para confirmar a associação. Tela de jogo

Crie uma nova cena com um nó raiz do tipo Interface de Usuário (Control), e dê a ela o nome MainGame. Associe o arquivo do tema salvo à propriedade Theme do nó raiz. Adicione como nós filhos à cena um Label e um LineEdit. Selecione o Label e altere as seguintes propriedades:
  • Horizontal Alignment: Center
  • Autowrap Mode: Word
  • Control/Layout/Layout Mode: Anchors
  • Control/Layout/Anchors Preset: Superior Largura Total
  • Control/Theme Overrides/Font Size: 32
  • Custom Minimum Size: Usar os mesmos valores de Control/Layout/Transform/Size
    Observação

    A Godot emite um warning caso não seja definido um tamanho mínimo para um label que está dentro de um container. Como não estamos usando containers ainda, esta definição tem somente o propósito de eliminar o warning.

  • Control/Layout/Layout Mode: Anchors
  • Control/Layout/Anchors Preset: Inferior Largura Total
  • Control/Theme Overrides/Font Size: 32

Exercícios

  1. Implemente a opção de o jogador solicitar uma palavra aleatória que seja válida para a sala corrente. Esta opção deve ser ativada quando o jogador digitar a palavra "random".
  2. Implemente a opção de exibir para o jogador a lista de palavras válidas para a sala corrente ao digitar a palavra "help".
  3. Implemente um estado de game over. Para isso, considere que o jogo se encerra sempre que o jogador atinge uma sala cujo único destino possível é a localização identificada pelo valor 0, que representa uma localização inexistente (dois exemplos desse tipo de sala são as salas 20 e 21). Nesse caso, exibir para o jogador um botão que permita a ele reiniciar a sessão de jogo (ou seja, reposicionar o jogador na sala inicial e atualizar o texto na tela).
  4. Incluir um modo de cheat, ativado pela palavra "cheat", que permita ao jogador se teleportar para qualquer sala imediatamente. O formato da entrada esperada deve ser "cheat X", em que X é o número da sala para onde o jogador deseja ir.
  5. Implementar uma função para capitalizar o texto na tela adequadamente, ou seja, somente a primeira letra de cada frase deve ser maiúscula.
